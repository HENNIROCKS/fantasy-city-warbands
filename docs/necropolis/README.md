# Necropolis

The app builds a gathering for Necropolis and shows it as cards. The campaign
is not in it yet, and the battle only in part.

1. **Before the game** – choose a Covenant, then [build the gathering](building.md):
   leader, minions, mana, spells and traits.
2. **The battle** – [choose who is fielded](battle.md) within the Deployment
   Limit and count hit points.
