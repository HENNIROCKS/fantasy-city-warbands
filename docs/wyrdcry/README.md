# Wyrdcry

How a game night runs with the app:

1. **Before the battle** – take a [hired sword](hired-swords.md) along if you
   want one.
2. **The battle** – count damage, states and rounds [on the cards](battle.md).
3. **After the battle** – the [aftermath](aftermath.md) asks for the dice and
   writes it all into the warband.
4. **Until the next one** – recruit, buy and correct [between battles](between-battles.md).

Coming from the Warband Deck or the Warband Builder? [Bring your warband over](from-the-deck.md).
