# Files and the roster

Your warbands live only in this browser on this device. There is no account
and no sync.

**Keep a copy.** On the start page, the arrow beside a warband saves it as a
file. On a phone this opens the share sheet. Do this before you clear the
browser or change phones.

**Bring it back.** **Import warband** on the start page reads the file, on this
device or another. The app says whether the file is newer or older than what
you have. It asks before an older file replaces a newer one.

**Not in the file:** photos and a battle still running.

**The roster.** The page icon beside a warband makes a PDF of its roster, to
print or to share.

**Home screen.** Add the app to your home screen. Safari can delete a site's
data after seven days without a visit, but mostly keeps it for an installed
app. The About page says how.
